# ASTA product shoe model

`asta-product-shoe.glb` is derived from the Khronos glTF Sample Assets
"Materials Variants Shoe" model.

- Original model: Shopify, 2021
- License: CC BY 4.0 International
- Source: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/MaterialsVariantsShoe

The distributed file was optimized for this website with glTF Transform:

- Meshopt geometry compression
- WebP texture compression
- Maximum texture resolution of 1024 by 1024
- Original size: 7,833,592 bytes
- Distributed size: approximately 557 KB
